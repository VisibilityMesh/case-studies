# Visibility Mesh case studies

Real applications of the [Visibility Mesh](https://visibilitymesh.com) AEO and GEO methodology, documented with data. These are worked examples of making ecommerce stores discoverable, understood, and recommended by AI assistants and answer engines.

## Case studies

- **[Fashion alternative comparisons](./fashion-alternatives)** — earning "alternatives to [premium brand]" AI answers for a live fashion store (Luna Fashion House). 21 researched brand comparisons, structured for answer engines. Includes a machine-readable dataset.
